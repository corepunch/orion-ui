# Ecstatica II source character library

Five original actors with source-preserving CAT controls replace the rejected synthetic character set.

- [Athletic Joe](joe/README.md)
- [Fuller woman villager](villager-full/README.md)
- [Round-bellied villager](villager-belly/README.md)
- [Slender villager](villager-slim/README.md)
- [Slender woman](freegirl/README.md)

Each folder contains the editable recipe, generated prefab, original calibrated reference and standing/bend/presentation/walk scenes. `scenes/source.blks` supplies the unchanged comparison. [Recipes](recipes/) are shared by the CLI and local slider studio. See [the workflow](../docs/volume-characters.md) for commands, controls and limits. The older Ecstatica I and II import libraries are retained.

[Lean](fullness-lean/README.md) and [heavy](fullness-heavy/README.md) Joe variants demonstrate whole-body fullness; [short](height-short/README.md) and [tall](height-tall/README.md) variants keep the same head dimensions. The [morph comparison scene](../scenes/volume_character_morphs.blks) shows both controls.

[Frame comparison](../scenes/volume_character_frames.blks): a 6-head regular frame, an 8-head narrow frame and an 8-head broad frame, all at the same minimum muscle and neutral fullness.
