# Third-party prototype artwork

These PNG atlases contain Microsoft Clippit (Clippy), the Microsoft Office
Assistant. Character artwork and animation data belong to Microsoft and are
not relicensed under Orion's software license.

Source: `third-party/clippitMS/CLIPPIT.ACS` as preserved in
https://github.com/Dimava/codex-clippy . The extraction's frame order and images
were repacked with `tools/import_assistant_clippy.py`; no extractor source code
is included. The preservation repository explicitly does not grant rights to
Microsoft artwork. This attribution is provenance, not a redistribution license.

Used as the temporary character for this assistant prototype.
