Agents · Ctrl+4

Three tasks in parallel. Each on its own branch, worktree and terminal.

Write one task per row and pick the agent. Git Client takes the current commit as the base, then reviews what each agent left as a real snapshot commit.

  1. 01Describe three tasks

    One prompt per row, Codex or Claude Code per row. Your CLIs use their usual accounts.

  2. 02Watch them work

    Every task gets a branch and a worktree. Agent Output opens its live terminal; Stop Agent stops only that one.

  3. 03Review a real commit

    A finished run is saved as a snapshot commit. Select it to read the diff against the original base.

  4. 04Run the reviewed revision

    Starts the default target from that revision's launch.xml in a separate detached worktree — build step included.

Launch targets

Run any branch the way it wants to be run.

A launch.xml lives with the code, so every worktree shows its own targets. Parameters, build steps and env included. No file? Targets are guessed from Makefile, Cargo, Go, Swift, CMake or package.json.

<!-- launch.xml — committed with the code -->
<launch project="api-gateway">
  <target name="Gateway" default="true"
          build="make build"
          run="bin/gateway --config ${config}">
    <param name="config"
           choices="config/local.yaml config/staging.yaml" />
  </target>
  <target name="Load test"
          run="k6 run --vus ${users} load/smoke.js">
    <param name="users" choices="10 100 1000" />
  </target>
  <target name="Unit tests" kind="test" run="go test ./..." />
</launch>
