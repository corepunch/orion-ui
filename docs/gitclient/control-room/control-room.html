Git Client как Control Room

Шесть вкладок терминала — ui, orca, blocks, tessera, x-com, lua-objc — превращаются в один список: проект → его worktree → кнопки запуска. Команды взяты из ваших Makefile и README; worktree — из git worktree list (у orca их четыре, все в /private/tmp). Кнопки кликабельны: запуск помечается как работающий.
